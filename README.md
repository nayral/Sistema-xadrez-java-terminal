# Sistema de Xadrez em Java (Terminal)

Este projeto é uma implementação de um sistema de xadrez em Java, com interface de linha de comando (terminal). Ele simula uma partida de xadrez completa, permitindo dois jogadores humanos alternarem jogadas diretamente no terminal, com verificação de regras, movimentos válidos e condições de xeque e xeque-mate.

## ♟️ Funcionalidades

- Movimentação completa das peças de xadrez
- Validação de jogadas conforme as regras oficiais
- Detecção de xeque e xeque-mate
- Sistema de turnos
- Exibição do tabuleiro no terminal
- Captura de peças com histórico
- Lógica estruturada orientada a objetos


## 🛠️ Tecnologias

- Java 11 ou superior
- IDE recomendada: IntelliJ, Eclipse ou VS Code
- Execução via terminal ou console embutido na IDE
